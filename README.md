# Workforce Data Analysis & KPI Dashboard

## Project Overview
This project uses Power BI to analyze workforce data and
provide insights into employee attrition, salary, hiring
trends, and workforce distribution.

## Objectives
- Analyze employee attrition patterns.
- Track workforce KPIs.
- Examine salary and hiring trends.
- Identify departments with higher attrition.
- Support data-driven HR decisions.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization

## Key Findings
- Analyzed workforce data covering 1,000 employees.
- Identified an overall attrition rate of 16.12%.
- Examined attrition patterns across departments.
- Analyzed salary, hiring trends, and workforce distribution.

## Business Value
The dashboard helps HR teams monitor workforce metrics,
investigate attrition patterns, and identify areas that
may require further analysis.
